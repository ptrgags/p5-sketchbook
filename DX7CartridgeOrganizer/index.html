🧪DX7 Cartridge Organizer (2026-08)

Loaded Voices

Cartridge (up to 32 voices)

🚧 Right now this is just the UI for patch management, the export is not yet implemented.

This page is not a p5.js sketch, but rather is a companion tool for DX7 Patch Viewer. It lets you import voices from one or more `.syx` files and reorganize them into a cartridge of 32 voices. The result can be loaded in Dexed.
