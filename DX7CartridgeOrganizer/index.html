🧪DX7 Cartridge Organizer (2026-08)

Loaded Voices

Cartridge (up to 32 voices)

🚧 Right now this is just the UI for voice management, the export button is not yet implemented.

Instructions:

  1. Load one or more DX7 cartridge file(s) (e.g. exported from Dexed) using the file input under the left column. This will add voices to the list.
  2. Select a voice from the left column.
  3. Press the Add button to add the voice to the end of the list on the right. NOTE: a cartridge holds no more than 32 voices.
  4. (Optional) Rename a voice by selecting it, editing the name in the text box, and pressing the Rename button. NOTE: DX7 voice names are limited to 10 ASCII characters.
  5. (Optional) Reorder voice in the right column by selecting one and pressing the up/down arrow buttons.
  6. (Optional) Remove a voice from the right column by selecting it and pressing the ❌ button.
  7. (🚧 NOT YET IMPLEMENTED!) Press the Export button to bundle the voices from the right column into a DX7 .syx file and download it. NOTE: The cartridge will always contain 32 voices. The end of the list will be padded with default sine wave voices titled "--INIT--".

This page is not a p5.js sketch, but rather is a companion tool for DX7 Patch Viewer. It lets you import voices from one or more `.syx` files and reorganize them into a cartridge of 32 voices. The result can be loaded in Dexed.
