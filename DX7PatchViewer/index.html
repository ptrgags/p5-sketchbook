DX7 Patch Viewer (2026-08)


Instructions: Load a .syx cartridge file (e.g. exported from Dexed) with the file picker. Then navigate through the voices by clicking the left/right sides of the canvas.

This sketch makes a diagram of FM (frequency modulation) synthesis patches. I wanted to make a layout that shows the parameters in the context of the algorithm diagram. The intent is to make it easier to study patches when learning FM synthesis.
